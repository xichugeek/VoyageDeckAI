## 上屏与简介命令

这些命令以 PowerShell 为准。缺少运行环境时，先从官方页面选择适配自己电脑架构的 Windows 安装程序，装好后重新打开 PowerShell。确认 Python 安装提供 `py` 启动器。[Git for Windows](https://git-scm.com/install/win) · [Node.js 22.x](https://nodejs.org/download/release/latest-v22.x/) · [Python 3.12 Windows 安装程序](https://www.python.org/downloads/release/python-31210/)。

### A · 检查环境

```powershell
git --version
node --version
py -3.12 --version
```

### B · 在选好的空文件夹克隆

```powershell
git clone https://github.com/xichugeek/VoyageDeckAI.git
Set-Location VoyageDeckAI
git log -1 --oneline
```

### C · 安装后端

```powershell
py -3.12 -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
```

### D · 安装前端

```powershell
Push-Location frontend
npm.cmd ci
Pop-Location
```

### E · 启动和验证

终端 A 在项目根目录运行脚本，保持窗口运行。

```powershell
.\scripts\dev.ps1
```

终端 B 验证健康状态并打开浏览器。

```powershell
Invoke-RestMethod 'http://127.0.0.1:8289/api/health'
Invoke-RestMethod 'http://127.0.0.1:5177/api/health'
Start-Process 'http://127.0.0.1:5177/'
```

本地指挥台是 [http://127.0.0.1:5177/](http://127.0.0.1:5177/)。如需固定从暂停的手动检查点练习，可另开 [http://127.0.0.1:5177/?mode=manual](http://127.0.0.1:5177/?mode=manual)。启动脚本提示端口已占用时，先确认是否有本项目的旧终端仍在运行，有则回到旧终端按 `Ctrl+C` 后重试。后端未就绪时查看项目内 `.local/backend-dev.log`。

## 剪映制作要求

- 开场使用新版实际屏录，至少在同一全景里看到一笔订单写入、GMV 增长、曲线推进和岗位交接。无需片头 Logo 等待。自动演示与手动段分别显示「自动轮播」和「手动审批」角标，成交额 $588 和 $98 归属各自场景。
- 安装段使用真实命令和输出。长命令放大，依赖下载可用「安装等待已压缩」标明跳切。字幕避开命令区、审批按钮和订单状态，版本、端口、金额逐个复核。点击、成功输出和两次审批停留至少两秒。
- 配普通话旁白，音频清晰。开场可配轻微节拍，其余段落以听清操作为主。使用随成片旁白时间对齐的 UTF-8 简体中文字幕。一般一行约 18 字，最多两行。命令以可复制的简介文本和命令卡为准。
- 封面 1920×1080。左侧两行大字「六智能体」「出海指挥台」，下方「Windows 实装教程」，右侧用新版真实画面裁出亮起的任务链与金额区，保留「模拟数据」。右上小字「西楚极客 031」，四边至少留 72 px。缩至手机缩略图时标题仍可读。
- 只使用项目自制界面、合成旁白和有权使用的图形、音乐、字体。录屏与截图范围限本项目和公开安装页面的必要内容。剪前逐段查看终端与浏览器录屏，音字幕与封面一起检查账号、凭据、真实客户数据、机器路径和生产日志。

**副标题**　VoyageDeck AI 本地安装与三个可复现案例

## 拍摄前核对

- 确认公开仓库默认分支 `main` 可以下载并按屏录命令安装。在片尾使用实测 Git 提交的短 SHA。仓库 [xichugeek/VoyageDeckAI](https://github.com/xichugeek/VoyageDeckAI)。
- 确认本地具备 Node.js 22.13 或以上的 22.x 版本、Python 3.12 和 Git。录制安装段时开一个新的工作目录，准备两个 PowerShell 窗口。
- 测试录屏环境时先跑一轮标准场景，正式录制用新浏览器标签页和全新的任务。暗色界面建议用 1920×1080 屏录，浏览器缩放 100%。审批按钮和指标口径可在剪辑时做局部放大。
- 计划现场入口为 [在线指挥台](https://voyagedeck.demo.xichugeek.com)。只有发布负责人确认公网 HTTPS、匿名首页和公开健康检查后，才把它加进片尾与简介；先用已验收的本地地址录制全套内容。测试区暂写「在线演示地址见置顶说明」。
- 录屏应显示「演示沙盒」或「模拟数据」标识。使用虚构订单和项目自制图形。账号、Token、生产地址或日志不要进入画面、剪映素材库、字幕和缩略图。

### 屏幕命令与简介复制区

安装段从一个新的工作目录开始。应用显示在浏览器，PowerShell 窗口保持运行。

```powershell
git clone https://github.com/xichugeek/VoyageDeckAI.git
Set-Location VoyageDeckAI
git log -1 --oneline
node --version
py -3.12 --version

py -3.12 -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
Push-Location frontend
npm.cmd ci
Pop-Location
.\scripts\dev.ps1
```

启动后在第二个 PowerShell 窗口核对接口，并打开浏览器页面。

```powershell
Invoke-RestMethod 'http://127.0.0.1:8289/api/health'
Invoke-RestMethod 'http://127.0.0.1:5177/api/health'
Start-Process 'http://127.0.0.1:5177/'
```

- 指挥台 [http://127.0.0.1:5177/](http://127.0.0.1:5177/)
- 后端健康检查 [http://127.0.0.1:8289/api/health](http://127.0.0.1:8289/api/health)
- 本地 API 文档 [http://127.0.0.1:8289/api/docs](http://127.0.0.1:8289/api/docs)
- 演示结束后在运行脚本的终端按 `Ctrl+C`。

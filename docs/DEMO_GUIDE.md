# 访客演示与录制指南

指挥台打开时载入履约阶段的暂停检查点。检查点由同一演示引擎重放生成，可点击「继续演示」结束这轮，也可创建独立任务验证三套情景。全程使用虚构商品、客户咨询、订单和广告支出。金额为 USD。

## 标准闭环 · 约 3 分钟

1. 点击「新建出海任务」，保留标准成功、美国、NomadPack、35% 毛利门槛和 60 美元模拟广告预算，再启动演示。
2. 选品执行时暂停，确认不会进入上架。恢复后点击候选 VD-OC02，查看 OrbitCase 的 19.4% 毛利及低于门槛的记录。也可把终端按「WARN」「选品官」筛选。
3. 在上架暂停点打开「查看产物」，浏览标题、五点描述、SEO 词和 SKU。关闭后点击「批准模拟草稿」。
4. 打开内容官看短视频分镜与社媒帖文，在投流关卡审核 26.80 美元的模拟消耗和渠道分配，然后批准模拟预算。
5. 展开客服官看三条英语咨询和人工复核项。履约完成后展开两条模拟订单，核对库存占用和发货事件。
6. 点击 GMV 进入计算口径，核对 98.00 美元 GMV、49.00 美元归因净销售额、26.80 美元广告支出、1.83× ROAS 和 19.72 美元估算贡献利润。打开复盘，下载 TXT。

## 换品和故障 · 约 2 分钟

- 「低毛利换品」默认首选 OrbitCase。按同样顺序完成两项批准，观察选品改选 AeroFold。两笔订单共 84.00 美元，库存仅支持一笔发货。另一笔模拟全额退款 42.00 美元，净销售额为 42.00 美元。
- 「故障恢复」批准上架后，内容官模拟超时。每次失败后点击「重试模拟岗位」，共允许两次人工重试。第三次尝试失败后，系统保留记录并跳过下游。
- 点底部「任务历史」回看旧任务。当前任务可单步前进、取消或确认重置。新开独立访客浏览器上下文可验证隔离。

录屏建议使用 1920×1080 并保持默认缩放。拍摄时把暂停、审批、低毛利、退款和重试的真实状态保留至少两秒。第 031 期包含可按步骤复现的安装口播、剪映交付规格及封面方向。 [第 031 期制作脚本](EPISODE_031.md)
